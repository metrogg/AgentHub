### 比赛 MVP 优先级

```
必须交付（Demo 核心）:
  IM 群聊界面 + @Agent 调度 + 流式输出
  飞书适配器（1 个平台即可）
  单轮任务拆解 + Agent 调度
  行级 Diff 展示 + 接受/拒绝
  iframe 实时预览 + 多设备切换
  静态网站一键部署

有时间就做（加分项）:
  多 Agent 群聊协作（Agent 间互相 @）
  Thread 多会话并行
  部署回滚机制
```
