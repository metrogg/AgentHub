## 模块 3：Agent Harness 引擎

### 3.1 模块概述

**定位**：Agent 的"操作系统"——负责 Agent Loop 驱动、Tool Registry 权限治理、四级上下文压缩、预算控制、Memory 系统。

**核心原则**：

> **Agent 负责局部智能，Harness 负责全局控制。**

Agent 只在自己的问题域内执行推理和行动，不参与全局调度决策。Harness 独占五项决策权：任务生命周期、执行计划裁决、Agent 路由、失败处理、硬终止条件。Harness 是 AgentHub 运行时底座的"最后一道防线"——任何 Agent 的行为都必须在 Harness 的治理边界之内。

**Harness Engineering 六大支柱**（参考顶级团队 512K 行代码的工业级实践）：

| 支柱 | 说明 | AgentHub 落地方式 |
|------|------|--------------------|
| 🗺️ 上下文架构 | 四级压缩管道，渐进降级，零 API 调用优先 | Snip → Micro → Collapse → Auto |
| ⛓️ 架构约束 | Fail-Closed 默认值，遗漏配置 = 不安全 | Tool Registry 九项元信息，默认值全偏保守 |
| 🔄 自验证循环 | transition 追踪，每次迭代可追溯、可断言 | `TransitionCause` 枚举 + Execution Log |
| 🧊 上下文隔离 | git worktree，Agent 并行操作文件系统级隔离 | Git Service + worktree 管理 |
| ♻️ 熵治理 | Auto 记忆管理，基于访问频次的遗忘机制 | 三层 Memory + 保留分数计算 |
| 🔌 可拆卸性 | 依赖注入，通过 `QueryDeps` 解耦 | `QueryConfig` 一次性快照 + DI 模式 |

### 3.2 Agent Loop 引擎（AsyncGenerator 驱动）

Agent Loop 是 Harness 的核心运行时——它是一个由 AsyncGenerator 驱动的 16 步迭代管线，参考 Claude Code / Codex 的 TAO（Think-Act-Observe）循环。

#### 3.2.1 16 步迭代管线

```
1. 技能发现预取 → 2. 工具结果预算应用 → 3. Snip Compact → 4. Micro Compact
→ 5. Context Collapse → 6. Auto Compact → 7. 阻塞限制检查 → ★ 8. 调用 Agent API
→ 9. 流式工具执行 → 10. 后采样 Hooks → 11. 中断处理 → 12. 停止 Hooks
→ 13. Token 预算检查 → 14. 附件消息注入 → 15. MCP 工具热更新 → 16. 继续下一轮
```

**各步骤详解**：

| 步骤 | 名称 | 职责 | 是否阻塞 Agent |
|------|------|------|----------------|
| 1 | 技能发现预取 | 扫描用户消息中的触发词，预加载对应 Skill（Markdown 指令），注入 system prompt | 否 |
| 2 | 工具结果预算应用 | 对上一轮工具调用结果做 Token 计数，扣减预算，超过阈值则裁剪结果内容 | 否 |
| 3 | Snip Compact | 基于标记边界裁剪历史消息，零 API 调用，最轻量压缩 | 否（压缩阶段） |
| 4 | Micro Compact | 利用 API 缓存编辑能力，删除特定工具调用结果，保持对话连贯 | 否（压缩阶段） |
| 5 | Context Collapse | 多轮工具调用结果折叠为结构化摘要（读时投影），保留原始消息 | 否（压缩阶段） |
| 6 | Auto Compact | LLM 生成对话摘要替换历史，最终防线 | 否（压缩阶段） |
| 7 | 阻塞限制检查 | `max_steps` / `max_tokens` / `max_duration` / `max_tool_calls` 四道硬闸检查 | 停止判断 |
| ★8 | 调用 Agent API | 通过适配器层调用 Agent 平台 API/CLI，流式消费响应 | **是（关键路径）** |
| 9 | 流式工具执行 | 解析 API 响应中的 tool_use，并行/串行执行，结果回写消息列表 | **是（关键路径）** |
| 10 | 后采样 Hooks | 在 Agent 回复后执行自定义 Hooks（如代码安全检查、Diff 生成） | 否 |
| 11 | 中断处理 | 处理用户中断请求（abort signal），优雅终止或挂起当前任务 | 中断 |
| 12 | 停止 Hooks | 检查是否需要停止（含恢复逻辑：reactive_compact_retry / collapse_drain_retry） | 停止判断 |
| 13 | Token 预算检查 | 计算当前消耗，判断所处分区（绿/黄/红/熔断），触发对应降级策略 | 否 |
| 14 | 附件消息注入 | 将系统消息（Memory 注入、MCP 工具变更通知）追加到下轮消息列表 | 否 |
| 15 | MCP 工具热更新 | 检测 MCP Server 状态变化，动态增删工具列表，通知 Agent | 否 |
| 16 | transition 追踪 | 记录本轮"为什么继续/为什么停止"，写入 Execution Log | 否 |

#### 3.2.2 AsyncGenerator 模式

Agent Loop 采用 AsyncGenerator 模式，天然支持流式输出、中断、背压：

```typescript
async function* agentLoop(params: LoopParams): AsyncGenerator<StreamEvent> {
  const state: LoopState = initializeState(params);

  while (true) {
    // === 前置预处理 ===
    const preResult = await preProcess(state, params.budget);
    if (preResult.shouldStop) {
      yield { type: 'done', usage: preResult.usage, transition: preResult.transition };
      break;
    }

    // === 调用 Agent API ===
    try {
      for await (const event of params.adapter.callAgent(
        state.messages,
        state.activeTools,
        { signal: state.abortController.signal, budget: state.budget }
      )) {
        if (event.type === 'text_delta') {
          state.assistantBuffer += event.content;
          state.tokenCounter.addOutput(estimateTokens(event.content));
        }
        if (event.type === 'tool_call') {
          state.pendingToolCalls.push(event);
        }
        yield event;
      }
    } catch (err) {
      if (isAbortError(err)) {
        yield { type: 'error', code: 'ABORTED', message: 'Agent call aborted' };
        break;
      }
      throw err;
    }

    // === 后置处理 ===
    const postResult = await postProcess(state, params);
    if (postResult.shouldStop) {
      yield { type: 'done', usage: state.budget.getUsage(), transition: postResult.transition };
      break;
    }

    // === transition 追踪 ===
    state.currentTransition = postResult.transition;
    state.executionLog.push({
      turn: state.turnCount,
      transition: postResult.transition,
      tokenUsage: state.budget.getUsage(),
      timestamp: Date.now(),
    });

    state.turnCount++;
  }
}
```

#### 3.2.3 transition 追踪

每次迭代必须记录"为什么继续"或"为什么停止"，使 Agent 执行路径可追溯、可断言、可审计。

```typescript
enum TransitionCause {
  NEXT_TURN                   = 'next_turn',
  MAX_TOKENS_RECOVERY         = 'max_tokens_recovery',
  REACTIVE_COMPACT_RETRY      = 'reactive_compact_retry',
  COLLAPSE_DRAIN_RETRY        = 'collapse_drain_retry',
  STOP_HOOK_BLOCKING          = 'stop_hook_blocking',
  TOKEN_BUDGET_CONTINUATION   = 'token_budget_continuation',
  HARD_STOP_MAX_STEPS         = 'hard_stop_max_steps',
  HARD_STOP_MAX_TOKENS        = 'hard_stop_max_tokens',
  HARD_STOP_MAX_DURATION      = 'hard_stop_max_duration',
  HARD_STOP_MAX_TOOL_CALLS    = 'hard_stop_max_tool_calls',
  USER_ABORT                  = 'user_abort',
  AGENT_FINISHED              = 'agent_finished',
  BUDGET_MELTDOWN             = 'budget_meltdown',
}
```

| 枚举值 | 含义 | 触发场景 |
|--------|------|----------|
| `next_turn` | 正常进入下一轮 | Agent 调用工具后返回结果，需要继续推理 |
| `max_tokens_recovery` | 超出单次 max_tokens 后恢复 | API 返回 `finishReason: 'length'`，自动续接 |
| `reactive_compact_retry` | 触发 reactive compact 重试 | 上下文接近窗口限制，压缩后重试当前轮 |
| `collapse_drain_retry` | collapse drain 后的重试 | 折叠历史后清空 pending，重新发起调用 |
| `stop_hook_blocking` | 停止 Hook 阻止继续 | 后采样 Hook 检测到安全问题，阻止执行 |
| `token_budget_continuation` | 预算允许继续 | 黄区/红区降级后预算仍有余量，继续执行 |
| `hard_stop_max_steps` | 硬停止：超过最大步数 | `max_steps`（默认 50） |
| `hard_stop_max_tokens` | 硬停止：超过最大 Token | `max_tokens`（默认 200K） |
| `hard_stop_max_duration` | 硬停止：超时 | `max_duration`（默认 30min） |
| `hard_stop_max_tool_calls` | 硬停止：超过最大工具调用次数 | `max_tool_calls`（默认 100） |
| `user_abort` | 用户主动中断 | 前端发送 abort 指令 |
| `agent_finished` | Agent 正常完成 | API 返回 `finishReason: 'stop'` |
| `budget_meltdown` | 预算熔断 | 剩余预算 < 5%，强制收束 |

### 3.3 Tool Registry 权限治理

Tool Registry 是 Harness 的工具统一注册入口与权限治理中心。所有工具（无论是内置工具还是 MCP Server 动态发现的工具）都必须在此登记后才能被 Agent 调用。

#### 3.3.1 九项元信息

每件工具登记以下九项元信息：

```typescript
interface ToolRegistration {
  name: string;
  description: string;
  inputSchema: ZodSchema;
  allowedAgents: string[];
  timeout: number;
  rateLimit: RateLimitConfig;
  riskLevel: RiskLevel;
  requiresHumanConfirmation: boolean;
  outputStructure: string;
  auditLogPolicy: AuditLogPolicy;
}

enum RiskLevel {
  LOW    = 'low',
  MEDIUM = 'medium',
  HIGH   = 'high',
}

interface RateLimitConfig {
  maxCallsPerMinute: number;
  maxCallsPerSession: number;
  cooldownMs: number;
}

enum AuditLogPolicy {
  NONE        = 'none',
  INPUT_ONLY  = 'input_only',
  FULL        = 'full',
}
```

| 元信息项 | 说明 | 示例 |
|----------|------|------|
| `name` | 工具唯一标识符 | `"read_file"` |
| `description` | 给 LLM 使用的工具描述（影响 Agent 的工具选择质量） | `"读取指定路径的文件内容。支持文本文件和图片文件。..."` |
| `inputSchema` | Zod Schema 定义输入参数，运行时校验 | `z.object({ filePath: z.string(), offset: z.number().optional() })` |
| `allowedAgents` | RBAC：允许调用此工具的 Agent 列表 | `["FrontendAgent", "BackendAgent"]` |
| `timeout` | 单次调用超时（毫秒） | 读文件 5000ms，执行命令 60000ms |
| `rateLimit` | 速率限制：每分钟最大调用次数、每会话最大调用次数、冷却时间 | `{ maxCallsPerMinute: 10, maxCallsPerSession: 50, cooldownMs: 1000 }` |
| `riskLevel` | 风险等级：低/中/高 | 读文件=低，写文件=中，执行命令=高 |
| `requiresHumanConfirmation` | 是否需要人工确认后才能执行 | 文件删除=true，代码格式化=false |
| `outputStructure` | 输出结果的描述，帮助 Agent 理解工具返回值格式 | `"返回 { content: string, lineCount: number, fileSize: number }"` |
| `auditLogPolicy` | 审计日志策略 | FULL=记录输入输出，INPUT_ONLY=只记录输入，NONE=不记录 |

#### 3.3.2 Fail-Closed 默认值

所有工具的默认值全部偏向保守——遗漏配置不会导致权限逃逸：

```typescript
const TOOL_DEFAULTS: Partial<ToolRegistration> = {
  isEnabled: () => true,
  isConcurrencySafe: () => false,
  isReadOnly: () => false,
  isDestructive: () => false,
  checkPermissions: (input: Record<string, unknown>) => ({
    behavior: 'allow' as const,
    updatedInput: input,
  }),
};
```

**核心逻辑**：
- `isConcurrencySafe` 默认 `false` → 假设工具不安全的并行，串行执行
- `isReadOnly` 默认 `false` → 假设工具会写入，需要权限确认
- 需显式将 `isConcurrencySafe` 设为 `true` 的工具：`GlobTool`, `GrepTool`, `FileReadTool`
- 需显式将 `isReadOnly` 设为 `true` 的工具：`GlobTool`, `GrepTool`, `FileReadTool`, `ListFilesTool`

#### 3.3.3 StreamingToolExecutor 设计

工具执行器负责根据工具的并发安全属性决定并行或串行执行策略：

```typescript
interface StreamingToolExecutor {
  executeConcurrent(
    calls: PendingToolCall[],
    registry: IToolRegistry,
    signal: AbortSignal
  ): AsyncGenerator<ToolCallResult>;

  executeSequential(
    calls: PendingToolCall[],
    registry: IToolRegistry,
    signal: AbortSignal
  ): AsyncGenerator<ToolCallResult>;
}
```

**执行策略**：

| 工具类型 | 执行模式 | 代表工具 |
|----------|----------|----------|
| 并发安全工具 | `Promise.all` 并行执行 | GlobTool, GrepTool, FileReadTool, WebSearchTool |
| 非并发工具 | 串行执行，独占资源 | BashTool, FileEditTool, FileWriteTool, GitTool |
| 高风险工具 | 串行 + 人工确认 | FileDeleteTool, DeployTool, DatabaseWriteTool |

**siblingAbortController 机制**：
- 并发工具组共享一个 `siblingAbortController`
- 任一并发工具执行出错时，发送 abort 信号取消所有兄弟工具
- **但不终止父级**（Agent Loop 继续运行，可重试失败的工具）
- 区分 `abortAll`（中断整个 Agent Loop）和 `siblingAbort`（只中断兄弟工具）

```typescript
class SiblingAbortController {
  private controller: AbortController;

  constructor(private parentSignal: AbortSignal) {
    this.controller = new AbortController();
    parentSignal.addEventListener('abort', () => this.controller.abort());
  }

  get signal(): AbortSignal {
    return this.controller.signal;
  }

  siblingAbort(): void {
    this.controller.abort();
  }
}
```

### 3.4 四级上下文压缩管道

参考顶尖项目的四级渐进压缩设计，从零 API 调用到全量 LLM 摘要，按照上下文窗口使用率自动触发。

#### 3.4.1 四级压缩详解

| 级别 | 名称 | 触发条件 | 机制 | API 调用 | 成本 |
|------|------|----------|------|----------|------|
| L1 | Snip Compact | 上下文利用率 > 70% | 基于标记边界裁剪历史，删除 snip 标记之前的所有消息 | 无 | 零 |
| L2 | Micro Compact | 上下文利用率 > 80% | 利用 API cache editing 能力，删除特定 tool_result（如图片数据、大文件内容），保留 tool_use 和关键结果摘要 | 无（cache 操作） | 零 |
| L3 | Context Collapse | 上下文利用率 > 90% | 多轮工具调用结果折叠为结构化摘要，原始消息保留但"读时投影"为摘要视图 | 无（前端处理） | 零 |
| L4 | Auto Compact | 上下文利用率 > 95% | LLM 生成对话摘要替换完整历史，最后防线 | **有** | 中（~500 tokens 输入） |

#### 3.4.2 L1 — Snip Compact（标记边界裁剪）

**原理**：在对话历史中插入 snip 标记（如 `<!-- SNIP -->`），当历史消息超过 snip 边界时，裁剪标记之前的所有消息。零 API 调用。

```typescript
interface SnipConfig {
  maxMessagesBeforeSnip: number;
  preserveSystemMessages: boolean;
  preserveLastNUserMessages: number;
}

async function snipCompact(
  messages: UnifiedMessage[],
  config: SnipConfig
): Promise<UnifiedMessage[]> {
  const snipIndex = messages.findIndex(m => m.metadata?.snipMarker === true);
  if (snipIndex === -1) return messages;

  const systemMessages = config.preserveSystemMessages
    ? messages.filter(m => m.role === 'system')
    : [];
  const recentUserMessages = messages
    .filter(m => m.role === 'user')
    .slice(-config.preserveLastNUserMessages);
  const afterSnip = messages.slice(snipIndex + 1);

  return [...systemMessages, ...recentUserMessages, ...afterSnip];
}
```

**触发条件**：
- 消息总数超过 `maxMessagesBeforeSnip`（默认 60 条）
- Agent Loop 第 3 步自动检测并执行

#### 3.4.3 L2 — Micro Compact（缓存编辑删除）

**原理**：利用 LLM API 的 cache editing 能力（如 Anthropic API 的 `cache_control`），删除特定的工具调用结果内容，但保留工具调用的元信息（名称、参数），维持对话的连贯性。

**适用场景**：
- 图片读取工具返回的 base64 数据（通常 10K-100K tokens）
- 大文件读取结果（超过 5000 字符的内容）
- Web 抓取返回的 HTML 全文

```typescript
interface MicroCompactConfig {
  maxToolResultLength: number;
  truncationStrategy: 'trim' | 'summarize' | 'remove';
  preserveToolNames: string[];
}

async function microCompact(
  messages: UnifiedMessage[],
  config: MicroCompactConfig
): Promise<UnifiedMessage[]> {
  return messages.map(msg => {
    if (msg.role !== 'tool') return msg;
    if (config.preserveToolNames.includes(msg.toolCallId ?? '')) return msg;

    const contentStr = typeof msg.content === 'string' ? msg.content : JSON.stringify(msg.content);
    if (contentStr.length <= config.maxToolResultLength) return msg;

    return {
      ...msg,
      content: `[TRUNCATED: ${contentStr.length} chars → ${config.maxToolResultLength}] ${contentStr.slice(0, config.maxToolResultLength)}`,
      metadata: { ...msg.metadata, microCompacted: true },
    };
  });
}
```

#### 3.4.4 L3 — Context Collapse（上下文折叠/读时投影）

**原理**：不修改原始消息列表，而是在"读时"将多轮工具调用结果投影为结构化摘要。Agent 看到的是结构化摘要，但原始数据保留用于审计和回放。

```typescript
interface CollapseConfig {
  collapseAfterNToolRounds: number;
  summaryTemplate: string;
}

async function contextCollapse(
  messages: UnifiedMessage[],
  config: CollapseConfig
): Promise<CollapsedView> {
  const toolRounds = extractToolRounds(messages);

  if (toolRounds.length <= config.collapseAfterNToolRounds) {
    return { messages, collapsedRounds: [] };
  }

  const roundsToCollapse = toolRounds.slice(0, -config.collapseAfterNToolRounds);
  const collapsedSummaries = roundsToCollapse.map(round => ({
    roundIndex: round.index,
    summary: generateStructuredSummary(round),
    originalMessageIndices: round.messageIndices,
  }));

  const projectedMessages = projectCollapsedView(messages, collapsedSummaries);

  return { messages: projectedMessages, collapsedRounds: collapsedSummaries };
}

interface CollapsedView {
  messages: UnifiedMessage[];
  collapsedRounds: CollapsedRound[];
}

interface CollapsedRound {
  roundIndex: number;
  summary: string;
  originalMessageIndices: number[];
}

function generateStructuredSummary(round: ToolRound): string {
  return JSON.stringify({
    toolCalls: round.calls.map(c => ({
      tool: c.name,
      args: truncateDeep(c.args, 200),
      resultSummary: summarizeResult(c.result, 300),
      duration: c.duration,
      success: !c.error,
    })),
    tokensConsumed: round.tokenUsage,
  });
}
```

#### 3.4.5 L4 — Auto Compact（LLM 对话摘要）

**原理**：调用 LLM 将完整对话历史压缩为一段摘要，替换原始消息列表。这是最后的防线，仅在上下文接近窗口极限时触发。

```typescript
interface AutoCompactConfig {
  summaryMaxTokens: number;
  preserveLastNTurns: number;
  summaryPrompt: string;
}

async function autoCompact(
  messages: UnifiedMessage[],
  config: AutoCompactConfig,
  adapter: IAgentAdapter
): Promise<UnifiedMessage[]> {
  const recentTurns = messages.slice(-config.preserveLastNTurns * 2);
  const toSummarize = messages.slice(0, -config.preserveLastNTurns * 2);

  if (toSummarize.length === 0) return messages;

  const summaryRequest: UnifiedMessage[] = [
    { role: 'system', content: config.summaryPrompt },
    { role: 'user', content: formatMessagesForSummary(toSummarize) },
  ];

  let summary = '';
  for await (const event of adapter.callAgent(summaryRequest, [], { maxTokens: config.summaryMaxTokens })) {
    if (event.type === 'text_delta') {
      summary += event.content;
    }
  }

  const summaryMessage: UnifiedMessage = {
    role: 'system',
    content: `[对话摘要] ${summary}`,
    metadata: { autoCompacted: true, originalMessageCount: toSummarize.length },
  };

  return [summaryMessage, ...recentTurns];
}
```

#### 3.4.6 压缩管道调度

```typescript
interface CompressionThresholds {
  snip: number;
  micro: number;
  collapse: number;
  auto: number;
}

const DEFAULT_THRESHOLDS: CompressionThresholds = {
  snip: 0.70,
  micro: 0.80,
  collapse: 0.90,
  auto: 0.95,
};

class CompressionPipeline implements ICompressionPipeline {
  async compress(
    messages: UnifiedMessage[],
    contextUtilization: number,
    thresholds: CompressionThresholds,
    adapter: IAgentAdapter
  ): Promise<CompressionResult> {
    if (contextUtilization > thresholds.auto) {
      const result = await autoCompact(messages, this.autoConfig, adapter);
      return { messages: result, level: 'auto', apiCallCost: result.length };
    }
    if (contextUtilization > thresholds.collapse) {
      const { messages: result } = await contextCollapse(messages, this.collapseConfig);
      return { messages: result, level: 'collapse', apiCallCost: 0 };
    }
    if (contextUtilization > thresholds.micro) {
      const result = await microCompact(messages, this.microConfig);
      return { messages: result, level: 'micro', apiCallCost: 0 };
    }
    if (contextUtilization > thresholds.snip) {
      const result = await snipCompact(messages, this.snipConfig);
      return { messages: result, level: 'snip', apiCallCost: 0 };
    }
    return { messages, level: null, apiCallCost: 0 };
  }
}

interface CompressionResult {
  messages: UnifiedMessage[];
  level: 'snip' | 'micro' | 'collapse' | 'auto' | null;
  apiCallCost: number;
}
```

### 3.5 预算熔断机制

MVP 阶段做基础 Token 计数统计 + 绿区正常执行，架构上预留完整的四级降级能力。

#### 3.5.1 四区降级模型

```
预算剩余 100% ████████████████████ 绿区：正常执行
预算剩余  50% ██████████ ────────── 黄区：压缩上下文
预算剩余  20% ████ ──────────────── 红区：切小模型 + 跳过 CoT
预算剩余   5% █ ──────────────────── 熔断区：强制收束，返回 partial result
```

| 区间 | 预算剩余 | 策略 | 具体行为 |
|------|----------|------|----------|
| 🟢 绿区 | > 50% | 正常执行 | 不限制任何行为，Agent 自由推理和调用工具 |
| 🟡 黄区 | 20% ~ 50% | 压缩上下文 | 主动触发压缩管道（L1→L2→L3），减少每轮 Token 消耗；限制单次工具调用结果的最大长度 |
| 🔴 红区 | 5% ~ 20% | 切换小模型 + 跳过 CoT | 切换到更便宜的模型（如 Claude Haiku 替代 Sonnet）；在 prompt 中指示 Agent 跳过详细思维链，直接给出结论 |
| 💥 熔断区 | < 5% | 强制收束 | 不再发起新的 LLM 调用；从已有结果中提取最佳 partial result 返回给用户；记录 `budget_meltdown` transition |

#### 3.5.3 预算消耗追踪

```typescript
class BudgetController implements IBudgetController {
  private total: number = 0;
  private consumed: number = 0;

  allocate(total: number): void {
    this.total = total;
    this.consumed = 0;
  }

  consume(usage: UsageStats): BudgetZone {
    this.consumed += usage.totalTokens;
    return this.getZone();
  }

  getRemaining(): number {
    return this.total - this.consumed;
  }

  getZone(): BudgetZone {
    const ratio = this.getRemaining() / this.total;
    if (ratio > 0.50) return BudgetZone.GREEN;
    if (ratio > 0.20) return BudgetZone.YELLOW;
    if (ratio > 0.05) return BudgetZone.RED;
    return BudgetZone.MELTDOWN;
  }

  triggerThreshold(zone: BudgetZone): boolean {
    return this.getZone() === zone;
  }
}
```

```typescript
function formatMemoriesForSystemPrompt(
  episodic: EpisodicMemory[],
  semantic: SemanticMemory[]
): string {
  const parts: string[] = ['## 相关记忆注入'];

  if (episodic.length > 0) {
    parts.push('### 历史经验');
    episodic.forEach(m => {
      parts.push(`- ${m.content} (重要度: ${m.importance.toFixed(1)})`);
    });

    parts.push('### 领域知识 / 规则');
    semantic.forEach(m => {
      parts.push(`- [${m.category}] ${m.content} (重要度: ${m.importance.toFixed(1)})`);
    });
  }

  return parts.join('\n');
}
```

#### 3.6.6 遗忘机制

基于多维评分自动管理记忆生命周期，防止记忆库膨胀和噪声累积：

```typescript
function calculateRetentionScore(memory: EpisodicMemory | SemanticMemory): number {
  const now = Date.now();
  const ageInDays = (now - memory.createdAt) / (1000 * 60 * 60 * 24);
  const daysSinceLastAccess = (now - memory.lastAccessedAt) / (1000 * 60 * 60 * 24);

  const ageFactor = Math.exp(-ageInDays / 180);
  const accessFactor = Math.min(memory.accessCount / 10, 1.0);
  const recencyFactor = Math.exp(-daysSinceLastAccess / 30);
  const importanceFactor = memory.importance;

  const weights = {
    age: 0.15,
    access: 0.25,
    recency: 0.25,
    importance: 0.35,
  };

  return (
    weights.age * ageFactor +
    weights.access * accessFactor +
    weights.recency * recencyFactor +
    weights.importance * importanceFactor
  );
}

enum RetentionAction {
  DELETE     = 'delete',
  COMPRESS   = 'compress',
  PRESERVE   = 'preserve',
}

function getRetentionAction(score: number): RetentionAction {
  if (score < 0.15) return RetentionAction.DELETE;
  if (score < 0.40) return RetentionAction.COMPRESS;
  return RetentionAction.PRESERVE;
}
```

**遗忘策略总结**：

| 保留分数 | 操作 | 说明 |
|----------|------|------|
| < 0.15 | **删除** | 低重要性 + 长时间未访问，从数据库中物理删除 |
| 0.15 ~ 0.40 | **压缩摘要** | 中等价值，将原文压缩为 1-2 句摘要保留，释放存储空间 |
| > 0.40 | **保留原文** | 高价值记忆，保留完整内容和 embedding |

**记忆整理（Consolidation）**：定期运行（如每 24 小时或每 N 个会话结束后），扫描记忆库并执行遗忘策略：

```typescript
interface ConsolidationResult {
  deleted: number;
  compressed: number;
  preserved: number;
  totalProcessed: number;
}

async function consolidateMemories(
  userId: string,
  memoryService: IMemoryService
): Promise<ConsolidationResult> {
  const memories = await memoryService.getAllForUser(userId);

  let deleted = 0, compressed = 0, preserved = 0;

  for (const memory of memories) {
    const score = calculateRetentionScore(memory);
    const action = getRetentionAction(score);

    switch (action) {
      case RetentionAction.DELETE:
        await memoryService.delete(memory.id);
        deleted++;
        break;
      case RetentionAction.COMPRESS:
        await memoryService.compress(memory.id);
        compressed++;
        break;
      case RetentionAction.PRESERVE:
        preserved++;
        break;
    }
  }

  return { deleted, compressed, preserved, totalProcessed: memories.length };
}
```

### 4.1 模块概述

### 4.3 Claude Code 适配器实现方案

#### 4.3.1 集成方式

通过 Bun 子进程 spawn Claude Code CLI，使用 `--print --output-format stream-json` 参数获取流式 JSON 输出。

```typescript
class ClaudeCodeAdapter implements IAgentAdapter {
  readonly name = 'Claude Code';
  readonly platform = 'claude-code';
  private currentProcess: Subprocess | null = null;
  private abortController: AbortController | null = null;

  async *callAgent(
    messages: UnifiedMessage[],
    tools: ToolDef[],
    options: CallOptions
  ): AsyncGenerator<StreamEvent> {
    this.abortController = new AbortController();

    const cliArgs = this.buildCliArgs(messages, tools, options);
    const proc = Bun.spawn(['claude', ...cliArgs], {
      stdin: 'pipe',
      stdout: 'pipe',
      stderr: 'pipe',
      signal: this.abortController.signal,
    });

    this.currentProcess = proc;

    const timeout = setTimeout(() => {
      this.abortController?.abort();
    }, options.maxTimeout ?? 300_000);

    try {
      for await (const line of this.readLines(proc.stdout)) {
        const event = this.parseJsonLine(line);
        if (event) yield event;
        if (event?.type === 'done') break;
      }

      clearTimeout(timeout);
      const exitCode = await proc.exited;
      if (exitCode !== 0) {
        const stderr = await new Response(proc.stderr).text();
        yield { type: 'error', code: 'CLI_EXIT_ERROR', message: stderr };
      }
    } finally {
      clearTimeout(timeout);
      this.currentProcess = null;
      if (!proc.killed) proc.kill();
    }
  }

  private buildCliArgs(
    messages: UnifiedMessage[],
    tools: ToolDef[],
    options: CallOptions
  ): string[] {
    const args: string[] = [
      '--print',
      '--output-format', 'stream-json',
    ];

    if (options.maxTokens) {
      args.push('--max-tokens', String(options.maxTokens));
    }

    const convertedMessages = this.convertMessages(messages);
    const convertedTools = this.convertTools(tools);

    args.push('--messages', JSON.stringify(convertedMessages));
    args.push('--tools', JSON.stringify(convertedTools));

    return args;
  }

  private convertMessages(messages: UnifiedMessage[]): ClaudeMessage[] {
    return messages.map(msg => ({
      role: msg.role,
      content: typeof msg.content === 'string'
        ? msg.content
        : msg.content.map(block => this.convertContentBlock(block)),
    }));
  }

  private convertContentBlock(block: ContentBlock): ClaudeContentBlock {
    switch (block.type) {
      case 'text':
        return { type: 'text', text: block.text! };
      case 'tool_use':
        return {
          type: 'tool_use',
          id: block.toolUse!.id,
          name: block.toolUse!.name,
          input: block.toolUse!.input,
        };
      case 'tool_result':
        return {
          type: 'tool_result',
          tool_use_id: block.toolResult!.toolUseId,
          content: block.toolResult!.content,
          is_error: block.toolResult!.isError,
        };
      default:
        return { type: 'text', text: JSON.stringify(block) };
    }
  }

  private convertTools(tools: ToolDef[]): ClaudeTool[] {
    return tools.map(tool => ({
      name: tool.name,
      description: tool.description,
      input_schema: tool.inputSchema,
    }));
  }

  private parseJsonLine(line: string): StreamEvent | null {
    try {
      const parsed = JSON.parse(line);
      switch (parsed.type) {
        case 'content_block_delta':
          if (parsed.delta?.type === 'text_delta') {
            return { type: 'text_delta', content: parsed.delta.text };
          }
          if (parsed.delta?.type === 'thinking_delta') {
            return { type: 'thinking', content: parsed.delta.thinking };
          }
          return null;

        case 'content_block_start':
          if (parsed.content_block?.type === 'tool_use') {
            return {
              type: 'tool_call',
              tool: parsed.content_block.name,
              args: parsed.content_block.input ?? {},
            };
          }
          return null;

        case 'message_delta':
          if (parsed.delta?.stop_reason) {
            return { type: 'done', usage: this.extractUsage(parsed.usage) };
          }
          return null;

        case 'error':
          return {
            type: 'error',
            code: 'CLAUDE_API_ERROR',
            message: parsed.error?.message ?? 'Unknown Claude error',
          };

        default:
          return null;
      }
    } catch {
      return null;
    }
  }

  private async *readLines(stream: ReadableStream<Uint8Array>): AsyncGenerator<string> {
    const reader = stream.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    try {
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() ?? '';

        for (const line of lines) {
          if (line.trim()) yield line;
        }
      }

      if (buffer.trim()) yield buffer;
    } finally {
      reader.releaseLock();
    }
  }
}
```

#### 4.3.2 进程管理

```typescript
interface SubprocessHandle {
  pid: number;
  startTime: number;
  status: 'running' | 'exited' | 'killed' | 'errored';
  exitCode: number | null;
  signal: AbortSignal;
}

class SubprocessManager {
  private activeProcesses: Map<string, SubprocessHandle> = new Map();

  register(adapterId: string, proc: Subprocess): SubprocessHandle {
    const handle: SubprocessHandle = {
      pid: proc.pid,
      startTime: Date.now(),
      status: 'running',
      exitCode: null,
      signal: new AbortController().signal,
    };

    this.activeProcesses.set(adapterId, handle);

    proc.exited.then(code => {
      handle.status = code === 0 ? 'exited' : 'errored';
      handle.exitCode = code;
    });

    return handle;
  }

  kill(adapterId: string): void {
    const handle = this.activeProcesses.get(adapterId);
    if (handle) {
      handle.status = 'killed';
      this.activeProcesses.delete(adapterId);
    }
  }

  getAliveProcesses(): number {
    let count = 0;
    for (const [, h] of this.activeProcesses) {
      if (h.status === 'running') count++;
    }
    return count;
  }
}
```

#### 4.3.3 超时策略

- **默认超时**：5 分钟（300,000ms）无响应则 abort
- **超时后行为**：发送 abort signal → 子进程被 kill → yield `error` 事件 → Harness 层接收 error，根据重试策略决定是否重试

### 4.4 Codex 适配器实现方案

#### 4.4.1 集成方式

通过 Bun 子进程 spawn Codex CLI（`codex exec --json`），与 Claude Code 适配器保持接口一致。

```typescript
class CodexAdapter implements IAgentAdapter {
  readonly name = 'Codex';
  readonly platform = 'codex';
  private currentProcess: Subprocess | null = null;
  private abortController: AbortController | null = null;

  async *callAgent(
    messages: UnifiedMessage[],
    tools: ToolDef[],
    options: CallOptions
  ): AsyncGenerator<StreamEvent> {
    this.abortController = new AbortController();

    const input = this.buildCodexInput(messages, tools, options);
    const proc = Bun.spawn(['codex', 'exec', '--json'], {
      stdin: 'pipe',
      stdout: 'pipe',
      stderr: 'pipe',
      signal: this.abortController.signal,
    });

    this.currentProcess = proc;

    const writer = proc.stdin.getWriter();
    writer.write(new TextEncoder().encode(JSON.stringify(input) + '\n'));
    writer.releaseLock();

    const timeout = setTimeout(() => {
      this.abortController?.abort();
    }, options.maxTimeout ?? 300_000);

    try {
      for await (const line of this.readLines(proc.stdout)) {
        const event = this.parseCodexOutput(line);
        if (event) yield event;
        if (event?.type === 'done') break;
      }

      clearTimeout(timeout);
      const exitCode = await proc.exited;
      if (exitCode !== 0) {
        const stderr = await new Response(proc.stderr).text();
        yield { type: 'error', code: 'CODEX_CLI_ERROR', message: stderr };
      }
    } finally {
      clearTimeout(timeout);
      this.currentProcess = null;
      if (!proc.killed) proc.kill();
    }
  }

  private buildCodexInput(
    messages: UnifiedMessage[],
    tools: ToolDef[],
    options: CallOptions
  ): CodexRequest {
    return {
      model: options.model ?? 'gpt-4o',
      messages: messages.map(m => ({
        role: m.role,
        content: typeof m.content === 'string' ? m.content : JSON.stringify(m.content),
      })),
      tools: tools.map(t => ({
        type: 'function',
        function: {
          name: t.name,
          description: t.description,
          parameters: t.inputSchema,
        },
      })),
      max_tokens: options.maxTokens,
      temperature: options.temperature,
      stream: true,
    };
  }

  private parseCodexOutput(line: string): StreamEvent | null {
    try {
      if (!line.startsWith('data: ')) return null;
      const data = line.slice(6);
      if (data === '[DONE]') return { type: 'done', usage: { inputTokens: 0, outputTokens: 0, cacheCreationTokens: 0, cacheReadTokens: 0, totalTokens: 0 } };

      const parsed = JSON.parse(data);
      const choice = parsed.choices?.[0];

      if (choice?.delta?.content) {
        return { type: 'text_delta', content: choice.delta.content };
      }

      if (choice?.delta?.tool_calls) {
        for (const tc of choice.delta.tool_calls) {
          if (tc.function?.name) {
            return { type: 'tool_call', tool: tc.function.name, args: JSON.parse(tc.function.arguments ?? '{}') };
          }
        }
      }

      if (choice?.finish_reason === 'stop' || choice?.finish_reason === 'tool_calls') {
        return {
          type: 'done',
          usage: {
            inputTokens: parsed.usage?.prompt_tokens ?? 0,
            outputTokens: parsed.usage?.completion_tokens ?? 0,
            cacheCreationTokens: 0,
            cacheReadTokens: 0,
            totalTokens: parsed.usage?.total_tokens ?? 0,
          },
        };
      }

      return null;
    } catch {
      return null;
    }
  }

  getCapabilities(): AgentCapability[] {
    return [
      {
        name: 'codex',
        description: 'OpenAI Codex CLI Agent',
        tags: ['general', 'code', 'reasoning'],
        supportedModels: ['gpt-4o', 'gpt-4o-mini', 'o3', 'o4-mini'],
        maxContextWindow: 128000,
        supportsStreaming: true,
        supportsToolCall: true,
        supportsVision: true,
        supportsThinking: false,
      },
    ];
  }

  supportsFeature(feature: AgentFeature): boolean {
    const supported: AgentFeature[] = [
      AgentFeature.STREAMING,
      AgentFeature.TOOL_CALL,
      AgentFeature.VISION,
    ];
    return supported.includes(feature);
  }

  async healthCheck(): Promise<AgentHealth> {
    try {
      const start = Date.now();
      const proc = Bun.spawn(['codex', '--version'], {
        stdout: 'pipe',
        stderr: 'pipe',
      });
      await proc.exited;
      return {
        status: 'healthy',
        latency: Date.now() - start,
        lastCheckedAt: Date.now(),
        consecutiveFailures: 0,
      };
    } catch (err) {
      return {
        status: 'unhealthy',
        latency: -1,
        lastError: String(err),
        lastCheckedAt: Date.now(),
        consecutiveFailures: 1,
      };
    }
  }

  abort(): void {
    this.abortController?.abort();
    if (this.currentProcess && !this.currentProcess.killed) {
      this.currentProcess.kill();
    }
  }

  async getUsage(): Promise<UsageStats> {
    return { inputTokens: 0, outputTokens: 0, cacheCreationTokens: 0, cacheReadTokens: 0, totalTokens: 0 };
  }

  async dispose(): Promise<void> {
    this.abort();
  }

  private async *readLines(stream: ReadableStream<Uint8Array>): AsyncGenerator<string> {
    const reader = stream.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    try {
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() ?? '';

        for (const line of lines) {
          if (line.trim()) yield line;
        }
      }

      if (buffer.trim()) yield buffer;
    } finally {
      reader.releaseLock();
    }
  }
}
```

```typescript
interface IMCPBridge {
  discoverTools(serverConfig: MCPServerConfig): Promise<MCPTool[]>;
  callTool(serverName: string, toolName: string, args: Record<string, unknown>): Promise<MCPToolResult>;
  listResources(serverName: string): Promise<MCPResource[]>;
  readResource(serverName: string, uri: string): Promise<MCPResourceContent>;
  setAllowlist(serverName: string, tools: string[]): void;
  disconnect(serverName: string): Promise<void>;
  getConnectedServers(): string[];
}

class MCPBridge implements IMCPBridge {
  private connections: Map<string, MCPConnection> = new Map();
  private allowlists: Map<string, Set<string>> = new Map();

  async discoverTools(config: MCPServerConfig): Promise<MCPTool[]> {
    const connection = await this.connect(config);
    const tools = await connection.listTools();

    const allowlist = this.allowlists.get(config.name);
    const filtered = allowlist
      ? tools.filter(t => allowlist.has(t.name))
      : tools;

    return filtered.map(t => ({
      ...t,
      serverName: config.name,
    }));
  }

  async callTool(
    serverName: string,
    toolName: string,
    args: Record<string, unknown>
  ): Promise<MCPToolResult> {
    const connection = this.connections.get(serverName);
    if (!connection) {
      throw new Error(`MCP server "${serverName}" is not connected`);
    }

    this.traceCall(serverName, toolName, args);

    const result = await connection.callTool(toolName, args);

    this.traceResult(serverName, toolName, result);

    return result;
  }

  setAllowlist(serverName: string, tools: string[]): void {
    this.allowlists.set(serverName, new Set(tools));
  }

  async disconnect(serverName: string): Promise<void> {
    const connection = this.connections.get(serverName);
    if (connection) {
      await connection.close();
      this.connections.delete(serverName);
    }
  }

  getConnectedServers(): string[] {
    return Array.from(this.connections.keys());
  }

  private async connect(config: MCPServerConfig): Promise<MCPConnection> {
    if (this.connections.has(config.name)) {
      return this.connections.get(config.name)!;
    }

    const connection = new MCPConnection(config);
    await connection.initialize();
    this.connections.set(config.name, connection);
    return connection;
  }

  private traceCall(serverName: string, toolName: string, args: Record<string, unknown>): void {
    console.log(JSON.stringify({
      event: 'mcp.call',
      server: serverName,
      tool: toolName,
      args: truncateDeep(args, 1000),
      timestamp: Date.now(),
    }));
  }

  private traceResult(serverName: string, toolName: string, result: MCPToolResult): void {
    console.log(JSON.stringify({
      event: 'mcp.result',
      server: serverName,
      tool: toolName,
      isError: result.isError,
      contentLength: JSON.stringify(result).length,
      timestamp: Date.now(),
    }));
  }
}
```

#### 4.6.1 AgentRouter 路由策略

路由策略的优先级：**能力匹配 → 负载均衡 → 健康检查 → 优先级排序**。

**路由算法**：

```typescript
class AgentRouter implements IAgentRouter {
  constructor(
    private registry: IAdapterRegistry,
    private healthChecker: HealthChecker
  ) {}

  async route(request: RouteRequest): Promise<RouteResult> {
    const candidates = this.registry.list()
      .filter(a => this.matchesCapabilities(a, request.requiredCapabilities))
      .filter(a => this.healthChecker.isHealthy(a.platform))
      .sort((a, b) => this.comparePriority(a, b, request));

    if (candidates.length === 0) {
      throw new Error('No healthy adapter matches the required capabilities');
    }

    const best = this.loadBalance(candidates);

    return {
      adapter: best,
      platform: best.platform,
      reason: `Capability match: ${request.requiredCapabilities.join(', ')}`,
      fallbackAvailable: candidates.length > 1,
    };
  }

  private matchesCapabilities(adapter: IAgentAdapter, required: string[]): boolean {
    const caps = adapter.getCapabilities();
    return required.every(r =>
      caps.some(c => c.tags.includes(r))
    );
  }

  private comparePriority(
    a: IAgentAdapter,
    b: IAgentAdapter,
    request: RouteRequest
  ): number {
    if (request.preferredPlatform) {
      if (a.platform === request.preferredPlatform) return -1;
      if (b.platform === request.preferredPlatform) return 1;
    }

    const priorityOrder = ['claude-code', 'codex'];
    const aIdx = priorityOrder.indexOf(a.platform);
    const bIdx = priorityOrder.indexOf(b.platform);
    return (aIdx === -1 ? 999 : aIdx) - (bIdx === -1 ? 999 : bIdx);
  }

  private loadBalance(adapters: IAgentAdapter[]): IAgentAdapter {
    return adapters[0];
  }

  getFallback(platform: string): IAgentAdapter | null {
    const healthy = this.registry.list()
      .filter(a => a.platform !== platform)
      .filter(a => this.healthChecker.isHealthy(a.platform));

    return healthy[0] ?? null;
  }

  getHealth(platform: string): AgentHealth {
    return this.healthChecker.getStatus(platform);
  }
```

#### 4.6.2 故障切换机制

```typescript
class FailoverHandler {
  async executeWithFailover<T>(
    primary: IAgentAdapter,
    fallback: IAgentAdapter | null,
    operation: (adapter: IAgentAdapter) => Promise<T>
  ): Promise<{ result: T; usedAdapter: string; failoverOccurred: boolean }> {
    try {
      const result = await operation(primary);
      return { result, usedAdapter: primary.platform, failoverOccurred: false };
    } catch (primaryError) {
      if (!fallback) throw primaryError;

      console.warn(
        `Failover: ${primary.platform} failed (${primaryError}), switching to ${fallback.platform}`
      );

      try {
        const result = await operation(fallback);
        return { result, usedAdapter: fallback.platform, failoverOccurred: true };
      } catch (fallbackError) {
        throw new AggregateError(
          [primaryError, fallbackError],
          `Both primary (${primary.platform}) and fallback (${fallback.platform}) failed`
        );
      }
    }
  }
}
```

```typescript
class HealthChecker {
  private statuses: Map<string, AgentHealth> = new Map();
  private timer: Timer | null = null;

  start(adapters: IAgentAdapter[], intervalMs: number = 30_000): void {
    this.timer = setInterval(async () => {
      for (const adapter of adapters) {
        try {
          const health = await adapter.healthCheck();
          this.statuses.set(adapter.platform, health);
        } catch (err) {
          const prev = this.statuses.get(adapter.platform);
          this.statuses.set(adapter.platform, {
            status: 'unhealthy',
            latency: -1,
            lastError: String(err),
            lastCheckedAt: Date.now(),
            consecutiveFailures: (prev?.consecutiveFailures ?? 0) + 1,
          });
        }
      }
    }, intervalMs);
  }

  stop(): void {
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = null;
    }
  }

  isHealthy(platform: string): boolean {
    const status = this.statuses.get(platform);
    if (!status) return true;
    return status.status !== 'unhealthy' || status.consecutiveFailures < 3;
  }

  getStatus(platform: string): AgentHealth {
    return this.statuses.get(platform) ?? {
      status: 'healthy',
      latency: 0,
      lastCheckedAt: Date.now(),
      consecutiveFailures: 0,
    };
  }
}
```

#### 4.7.1 AdapterRegistry

```typescript
interface IAdapterRegistry {
  register(adapter: IAgentAdapter): void;
  unregister(platform: string): void;
  get(platform: string): IAgentAdapter | null;
  list(): IAgentAdapter[];
  getByPlatform(platform: string): IAgentAdapter | null;
}

class AdapterRegistry implements IAdapterRegistry {
  private adapters: Map<string, IAgentAdapter> = new Map();
  private maxConcurrentPerPlatform: number = 5;
  private activeCallCounts: Map<string, number> = new Map();

  register(adapter: IAgentAdapter): void {
    if (this.adapters.has(adapter.platform)) {
      throw new Error(`Adapter for platform "${adapter.platform}" is already registered`);
    }
    this.adapters.set(adapter.platform, adapter);
    this.activeCallCounts.set(adapter.platform, 0);
  }

  unregister(platform: string): void {
    const adapter = this.adapters.get(platform);
    if (adapter) {
      adapter.dispose();
      this.adapters.delete(platform);
      this.activeCallCounts.delete(platform);
    }
  }

  get(platform: string): IAgentAdapter | null {
    return this.adapters.get(platform) ?? null;
  }

  list(): IAgentAdapter[] {
    return Array.from(this.adapters.values());
  }

  getByPlatform(platform: string): IAgentAdapter | null {
    return this.adapters.get(platform) ?? null;
  }

  canAcceptCall(platform: string): boolean {
    const count = this.activeCallCounts.get(platform) ?? 0;
    return count < this.maxConcurrentPerPlatform;
  }

  incrementCallCount(platform: string): void {
    const count = this.activeCallCounts.get(platform) ?? 0;
    this.activeCallCounts.set(platform, count + 1);
  }

  decrementCallCount(platform: string): void {
    const count = this.activeCallCounts.get(platform) ?? 0;
    this.activeCallCounts.set(platform, Math.max(0, count - 1));
  }
}
```

```typescript
class ConcurrencyGuard {
  constructor(private registry: IAdapterRegistry) {}

  async executeWithGuard<T>(
    platform: string,
    fn: () => Promise<T>
  ): Promise<T> {
    while (!this.registry.canAcceptCall(platform)) {
      await new Promise(resolve => setTimeout(resolve, 100));
    }

    this.registry.incrementCallCount(platform);
    try {
      return await fn();
    } finally {
      this.registry.decrementCallCount(platform);
    }
  }
}
```
