## 一、功能清单拆解（Coze 功能全景图）

### 1.1 核心功能架构

```
┌─────────────────────────────────────────────────────────┐
│                    Coze 3.0 功能全景图                    │
├─────────────────────────────────────────────────────────┤
│  协作层  │ 多 Agent 协作群聊 · 项目制管理 · 跨端同步        │
├─────────────────────────────────────────────────────────┤
│   Agent  │ Agent 定义 · 一键接入 · 职业模板 · 长期记忆       │
├─────────────────────────────────────────────────────────┤
│  创作层  │ 扣子编程 · 视频创作 · 文档生成 · 工作流           │
├─────────────────────────────────────────────────────────┤
```

### 1.2 功能拆解详表

#### 功能 1：多 Agent 协作群聊（P0 - 核心功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 创建项目 → ② 邀请 Agent/成员 → ③ 在群聊中 @Agent 派发任务 → ④ Agent 自动执行并返回结果 → ⑤ 人类审核/迭代 → ⑥ 产物沉淀 |
| **前端界面元素** | 左侧 Agent 列表（头像、名称、状态）、中间对话流（人类消息/Agent 消息区分样式）、底部输入框（支持 @ 和下拉选择）、右侧产物预览区 |
| **交互细节** | • @Agent 时弹出下拉菜单，显示可用 Agent 列表<br>• Agent 回复时显示"正在输入"状态<br>• 支持文件拖拽上传<br>• 点击 Agent 头像可查看其详细能力和配置 |
| **优先级** | **P0** - 这是 Coze 3.0 最核心的差异化功能，必须实现 |

#### 功能 2：项目制管理（P0 - 核心功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 创建项目（选择类型：通用/编程/视频）→ ② 配置项目成员和 Agent → ③ 项目内对话和产物自动归类 → ④ 查看项目资产库 → ⑤ 项目间切换 |
| **前端界面元素** | 项目列表页（卡片式展示）、项目详情页（三栏布局）、项目设置面板、资产库（文件/代码/视频分类存储） |
| **交互细节** | • 项目卡片显示进度条/最近活动时间<br>• 项目内所有对话共享上下文<br>• 产物自动按类型归类（文档/代码/视频/图片）<br>• 支持项目模板快速创建 |
| **优先级** | **P0** - 支撑多 Agent 协作的基础组织单元 |

#### 功能 3：Agent 定义与接入（P0 - 核心功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 选择创建方式（标准创建/AI 创建）→ ② 配置 Agent 人设（提示词）→ ③ 选择模型和参数 → ④ 添加技能（插件/工作流/知识库）→ ⑤ 测试调试 → ⑥ 发布/接入 |
| **前端界面元素** | 创建向导（分步骤）、人设编辑区（富文本）、技能 marketplace（图标+描述）、模型选择器（下拉+参数调节）、预览调试面板 |
| **交互细节** | • AI 创建模式：用户用自然语言描述，系统自动生成配置<br>• 支持本地 Agent 一键接入（Claude Code/Codex CLI/OpenClaw）<br>• 模型参数实时调节（Temperature/Max Tokens）<br>• 技能拖拽添加 |
| **优先级** | **P0** - Agent 是系统的核心角色，定义和接入能力必须完善 |

#### 功能 4：扣子编程（P1 - 重要功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 创建编程项目 → ② 对话式描述需求 → ③ Agent 生成代码 → ④ 预览效果 → ⑤ 迭代修改 → ⑥ 一键部署 |
| **前端界面元素** | 代码编辑器（Monaco 风格）、预览 iframe、文件树、终端面板、部署配置页 |
| **交互细节** | • 对话与代码生成联动（自然语言 → 代码）<br>• 支持导入 GitHub 项目<br>• 云端沙箱环境（无需本地配置）<br>• 一键部署到域名/云服务器 |
| **优先级** | **P1** - 与主对话系统已打通，是重要的生产力场景 |

#### 功能 5：视频创作（P1 - 重要功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 创建视频项目 → ② 对话生成剧本 → ③ 分镜设计 → ④ 视频生成（Seedance 2.0）→ ⑤ 对话式剪辑 → ⑥ 导出剪映工程 |
| **前端界面元素** | 剧本编辑器、分镜故事板、视频预览器、时间轴、素材库、导出面板 |
| **交互细节** | • 全流程对话式操作（无需手动剪辑）<br>• 支持多人协作编辑<br>• 项目内素材共享<br>• 导出专业格式（剪映工程文件） |
| **优先级** | **P1** - 特定领域深度功能，展示产品上限 |

#### 功能 6：跨端同步（P1 - 重要功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 桌面端创建任务 → ② 移动端查看进度 → ③ 移动端继续推进 → ④ 桌面端 Agent 处理本地文件 |
| **前端界面元素** | 各端统一的项目列表、对话界面、文件管理器、本地文件授权面板 |
| **交互细节** | • 三端（桌面/macOS/Windows、移动/iOS Android、网页）全量更新<br>• 桌面端可授权 Agent 访问本地文件<br>• 移动端可远程操作电脑文件<br>• 实时同步对话和产物 |
| **优先级** | **P1** - 提升用户体验完整度，但 MVP 可先实现网页端 |

#### 功能 7：行业技能包（P2 - 加分项）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 选择行业模板 → ② 一键加载技能包 → ③ 获得专家级 Agent 能力 |
| **前端界面元素** | 模板 marketplace（分类浏览）、技能包详情页、一键加载按钮 |
| **交互细节** | • 覆盖自媒体、法律、金融、科研、医疗等领域<br>• 内置行业数据集和权威知识<br>• 职业模板快速创建专家 Agent |
| **优先级** | **P2** - 生态建设功能，MVP 后可逐步扩展 |

#### 功能 8：/ 命令触发技能（P1 - 重要功能）

| 维度 | 详情 |
|------|------|
| **用户操作流程** | ① 输入 "/" → ② 弹出技能下拉菜单 → ③ 选择或搜索技能 → ④ 触发执行 |
| **前端界面元素** | 底部输入框的 "/" 触发器、下拉菜单（图标+名称+描述）、技能分类标签 |
| **交互细节** | • 支持技能搜索和分类筛选<br>• 常用技能置顶<br>• 技能执行结果在对话中展示 |
| **优先级** | **P1** - 快捷操作入口，提升效率 |

## 二、交互设计分析

### 2.1 整体布局架构

```
┌────────────────┬────────────────────────┬─────────────────┐
│   左侧导航栏    │      中间对话区        │    右侧预览区    │
│                │                        │                 │
│ • 项目列表      │  ┌─────────────────┐  │  ┌───────────┐  │
│ • Agent 列表   │  │ 人类消息（右）   │  │  │ 产物预览   │  │
│ • 成员列表     │  ├─────────────────┤  │  │ 代码/文件  │  │
│ • 设置入口     │  │ Agent 消息（左） │  │  │ 视频/网页  │  │
│                │  ├─────────────────┤  │  └───────────┘  │
│                │  │ 系统通知（中）   │  │                 │
│                │  └─────────────────┘  │                 │
│                │                        │                 │
│                │  ┌─────────────────┐  │                 │
│                │  │ 输入框 + / 命令  │  │                 │
│                │  └─────────────────┘  │                 │
└────────────────┴────────────────────────┴─────────────────┘
```

### 2.2 左侧 Agent 列表 UI 设计

| 设计元素 | 具体实现 | 复刻建议 |
|---------|---------|---------|
| **头像** | 圆形头像，支持自定义上传或 AI 生成 | 使用统一风格的头像组件，支持文字头像（首字母）作为 fallback |
| **状态指示** | 在线（绿点）、忙碌（黄点）、离线（灰点） | 实现简单状态机：思考中/执行中/空闲 |
| **名称** | Agent 名称 + 角色标签（如"创作 Agent"） | 名称限制 20 字符，支持 emoji |
| **能力标签** | 小型标签展示核心技能（如"编程""写作"） | 最多显示 3 个，超出折叠 |
| **排序** | 按最近活动时间或自定义顺序 | 支持拖拽排序 + 最近活跃置顶 |
| ** hover 效果** | 显示 Agent 简介和快捷操作（@/查看详情） | 延迟 300ms 触发，避免误触 |

### 2.3 中间对话流 UI 设计

#### 消息类型区分

| 消息类型 | 视觉表现 | 交互行为 |
|---------|---------|---------|
| **人类消息** | 右侧气泡，蓝色背景，用户头像 | 支持编辑、删除、引用 |
| **Agent 消息** | 左侧气泡，白色/灰色背景，Agent 头像 | 支持点赞、反馈、重新生成 |
| **系统通知** | 居中，灰色小字，无头像 | 仅查看，支持折叠 |
| **文件卡片** | 独立卡片，文件图标 + 名称 + 大小 | 点击预览，支持下载 |
| **代码块** | 深色背景，语法高亮，行号 | 支持复制、在编辑器中打开 |
| **产物卡片** | 大面积预览（iframe/图片），边框高亮 | 支持全屏预览、分享、导出 |

#### 对话流交互细节

- **新消息动画**：Agent 回复时，消息从底部滑入，带"正在输入"的打字机效果
- **上下文感知**：鼠标 hover 到 Agent 回复时，显示它正在回应哪条人类消息
- **快捷操作**：Agent 消息底部显示操作栏（复制、重新生成、反馈有用/无用）
- **文件处理**：拖拽文件到输入框自动上传，上传进度条显示
- **无限滚动**：历史消息自动加载，保持滚动位置

### 2.4 右侧产物预览 UI 设计

| 产物类型 | 预览方式 | 交互功能 |
|---------|---------|---------|
| **网页/小程序** | iframe 内嵌预览 | 支持刷新、在浏览器打开、分享链接 |
| **代码文件** | Monaco 编辑器（只读/可编辑） | 支持复制、下载、在项目中打开 |
| **视频** | 视频播放器组件 | 播放/暂停、进度条、全屏、下载 |
| **图片** | 图片预览组件 | 放大查看、下载、分享 |
| **文档** | Markdown 渲染 + 目录导航 | 导出 PDF、分享、打印 |

### 2.5 / 命令触发技能下拉菜单设计

```
用户输入 "/" 后：

┌────────────────────────────┐
│  🔍 搜索技能...              │
├────────────────────────────┤
│  常用技能                    │
│  • /编程  - 开始编程项目      │
│  • /视频  - 开始视频创作      │
│  • /文档  - 生成文档         │
├────────────────────────────┤
│  全部技能                    │
│  📁 文件处理                 │
│    • /读取文件               │
│    • /写入文件               │
│  💻 编程开发                 │
│    • /生成代码               │
│    • /调试代码               │
│  🎨 内容创作                 │
│    • /生成图片               │
│    • /生成视频               │
└────────────────────────────┘
```

**设计要点**：
- 输入 "/" 立即触发，无需等待
- 支持键盘上下导航（↑/↓）和回车确认
- 搜索支持拼音和关键词匹配
- 技能分类图标化，提升识别效率

### 2.6 @mention 调度 Agent 交互流程

```
用户输入流程：

1. 在输入框输入 "@"
   ↓
2. 弹出 Agent 选择下拉菜单
   ┌─────────────────────────┐
   │ @ 选择 Agent...          │
   ├─────────────────────────┤
   │ 🤖 扣子 Agent (在线)      │
   │ 📝 创作 Agent (在线)      │
   │ 💻 编程 Agent (忙碌)      │
   │ 🔍 调研 Agent (在线)      │
   └─────────────────────────┘
   ↓
3. 用户选择 Agent，输入框显示："@编程 Agent 帮我写个排序算法"
   ↓
4. 发送消息后，系统路由到对应 Agent
   ↓
5. Agent 思考中状态显示（输入框上方小字提示）
   ↓
6. Agent 回复出现在对话流中，带有 @mention 的上下文引用
```

**关键交互规则**：
- 一个消息可 @ 多个 Agent（并行任务）
- 被 @ 的 Agent 收到完整上下文（项目内历史对话）
- Agent 回复时自动引用被 @ 的消息
- 支持 @ 全体成员（@all）触发所有 Agent 广播

### 2.7 跨端同步交互设计

| 端 | 核心场景 | 交互特点 |
|---|---------|---------|
| **桌面端** | 复杂编程、文件处理、多窗口协作 | 支持本地文件授权、系统级快捷键、大屏幕三栏布局 |
| **网页端** | 通用任务、快速访问、无需安装 | 功能对齐桌面端、响应式布局、PWA 支持 |
| **移动端** | 查看进度、简单操作、移动场景 | 单栏布局、手势操作、推送通知、语音输入 |

**同步机制**：
- 实时 WebSocket 同步对话消息
- 产物变更自动推送到所有端
- 离线编辑支持，联网后自动合并
- 冲突解决：时间戳优先 + 手动合并提示

| Coze 功能 | 对应赛题考察点 | 匹配度 | 说明 |

### 3.2 赛题要求但 Coze 没有的功能（差异化机会）

| 赛题要求 | Coze 现状 | 差异化机会 |
|---------|----------|-----------|
| **Orchestrator 自动调度** | 需要用户手动 @Agent 触发 | **自动任务拆解 + Agent 调度** 是核心差异化点 |
| **BackendAgent 协作生成** | 单个 Agent 独立执行 | **多 Agent 流水线协作** 展示复杂任务拆解 |
| **产物 iframe 预览 + 代码编辑** | 有预览，但编辑能力有限 | **Monaco 实时编辑 + 即时预览** 提升技术美感 |
| **30 秒自动调度展示** | 需要手动触发每个 Agent | **自动流水线演示** 更具震撼力 |

### 3.3 Coze 有但赛题没要求的功能（可作为亮点）

| Coze 功能 | 亮点价值 | 是否在 MVP 中实现 |
|----------|---------|----------------|
| 跨端同步（桌面/移动/网页） | 展示工程实力 | 否，MVP 后扩展 |
| 视频创作全流程 | 内容创作场景拓展 | 否，P2 功能 |
| 本地 Agent 接入（Claude Code 等） | 生态开放性 | 可作为差异化亮点纳入 |
| 行业技能包 | 垂直领域深化 | 否，MVP 后扩展 |
| 云端沙箱 + 一键部署 | 完整开发闭环 | 核心功能，建议纳入 |

## 四、复刻建议

### 4.1 MVP 功能优先级（第一阶段：最小可用）

```
第一阶段（MVP - 1-2 周）
├── P0 必须实现
│   ├── 多 Agent 协作群聊（核心）
│   │   ├── 群聊对话流
│   │   ├── @mention 调度
│   │   └── 消息上下文共享
│   ├── 项目制管理（基础）
│   │   ├── 创建/切换项目
│   │   └── 项目内对话隔离
│   └── Agent 定义与接入
│       ├── 基础 Agent 创建
│       ├── 人设提示词配置
│       └── 模型选择（至少 1 个）
├── P1 重要功能
│   ├── 产物预览（iframe + 代码高亮）
│   ├── / 命令触发技能
│   └── 文件上传/下载
└── P2 加分项
    └── 简单行业模板
```

### 4.2 第二阶段功能（扩展完善）

```
第二阶段（1-2 周）
├── 核心增强
│   ├── Orchestrator 自动调度（自动拆解任务）
│   ├── BackendAgent 协作流水线
│   ├── 产物 Monaco 编辑器集成
│   └── 一键部署到云端
├── 体验优化
│   ├── 左侧 Agent 列表完善（状态、排序）
│   ├── 右侧预览区增强
│   ├── 消息类型丰富（文件、图片、代码）
│   └── 对话流动画优化
└── 生态扩展
    ├── 行业模板（3-5 个）
    └── 本地 Agent 接入方案
```

### 4.3 实现难度评估

## 五、关键交互细节总结

### 5.1 消息可见性规则（复刻核心）

根据 Coze 3.0 和 Kimi Claw 的机制，消息可见性规则如下：

```
规则 1: 单 @ 消息
用户发送: "@AgentA 帮我写个排序算法"
可见性: 
  - 发送者: 可见
  - AgentA: 可见（收到任务）
  - 其他 Agent: 不可见
  - 人类成员: 可见（群聊共享上下文）

规则 2: 多 @ 消息
用户发送: "@AgentA @AgentB 一起完成这个需求"
可见性:
  - 发送者: 可见
  - AgentA: 可见（看到完整消息，知道 AgentB 也被 @）
  - AgentB: 可见（看到完整消息，知道 AgentA 也被 @）
  - 其他 Agent: 不可见

规则 3: 无 @ 消息
用户发送: "大家帮我看看这个方案"
可见性:
  - 发送者: 可见
  - 所有 Agent: 不可见（等待被 @ 或 Orchestrator 调度）
  - 所有人类成员: 可见

规则 4: Agent 回复
AgentA 回复: "收到，我来处理排序算法"
可见性:
  - 所有项目成员（人类 + Agent）: 可见
  - 回复自动引用被 @ 的消息
```

## 六、竞品对比与差异化建议

### 6.1 与 Coze 3.0 的对比

| 维度 | Coze 3.0 | AgentHub（建议定位） |
|------|---------|---------------------|
| **核心交互** | 群聊 + @mention | 群聊 + 自动调度（差异化） |
| **Agent 接入** | 本地 + 云端 | 本地 + 云端 + 自定义（对齐） |
| **任务调度** | 手动 @ 触发 | **自动拆解 + 智能路由**（核心差异） |
| **产物展示** | iframe + 基础编辑 | **Monaco + 实时预览**（体验升级） |
| **协作模式** | 人 + Agent 协作 | 人 + Agent + **Agent 间协作**（深度） |
| **部署能力** | 一键部署到云平台 | 一键部署 + **本地运行**（灵活） |
| **开放生态** | 行业技能包 | **开源框架 + 社区贡献**（开放） |

### 6.2 差异化建议

1. **自动调度是核心差异**：Coze 需要用户手动 @Agent，AgentHub 可以展示 Orchestrator 自动拆解和调度的能力，更符合"智能协作"的愿景

2. **Agent 间协作**：不仅人 @Agent，Agent 之间也可以互相调用和协作，形成真正的"团队"

3. **开源 + 可复刻**：Coze 是闭源商业产品，AgentHub 赛题强调可复刻性，这是天然优势

4. **技术美感**： Monaco 编辑器 + 实时预览，在开发者群体中有天然吸引力

## 七、总结与建议

### 7.1 核心结论

Coze 3.0 是一个成熟的多 Agent 协作平台，其**群聊式交互**和**项目制管理**是核心创新点。对于 AgentHub 赛题：

1. **必须复刻的基础**：群聊交互、@mention 调度、项目隔离、产物预览
2. **建议强化的差异**：自动调度（Orchestrator）、Agent 间协作、技术美感（Monaco）
3. **可以后续扩展**：跨端同步、视频创作、行业模板
