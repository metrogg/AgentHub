
# Coze 3.0 完整分析框架

## 1. 核心定位
"新一代 AI 团队，从扣子开始" —— 多 Agent 协作的职场 AI 平台，人和 Agent 像真实团队一样并肩作战。

## 2. 核心功能模块

### 2.1 多 Agent 协作群聊（主功能）
- 左侧：Agent 列表（扣子 Agent、编程 Agent、视频 Agent、法务 Agent、创作 Agent）
- 中间：对话流（人类和 Agent 混合消息，Agent 消息带头像和名称）
- 右侧：移动端预览
- 关键交互：@Agent 调度，Agent 自动分工、协作、汇报
- 流程示例：人类发起需求 → 扣子 Agent（Coordinator）拉流程 → 创作 Agent 写脚本 → 法务 Agent 审查 → 视频 Agent 生成 → 编程 Agent 部署 → 扣子 Agent 闭环总结
- 技能引用：输入 / 快速引用技能或文件

### 2.2 项目制管理
- 多项目创建，专项管理
- 每个项目独立存储空间，沉淀项目产出内容
- 支持人和 Agent 同频工作

### 2.3 Agent 定义与接入
- 三种接入方式：
  1. 扣子 Agent（云原生，满配在线，云手机/云电脑，长期记忆）
  2. 行业模板和技能包（开箱即用）
  3. 本地工具接入（Claude Code / Codex CLI / Openclaw 等一键接入）
- 模型自由切换：Doubao-Seed / Kimi / GLM / Minimax
- 完整 Harness 能力：技能调用、长期记忆、工作台（日程、邮箱、云电脑、云手机）
- 越用越懂你：持续积累偏好与知识，成为专属数字分身

### 2.4 扣子编程（Vibe Coding）
- 通过自然语言对话开发小程序、App、网页应用、智能体、工作流、技能 Skill
- 云端沙箱环境：内置文件系统、终端与预览工具
- 集成资源：数据库、对象存储、AI 模型、联网检索等
- 一键部署：域名、云服务器、SSL 证书等链路一键打通
- 版本管理与持续运维

### 2.5 视频创作
- 打通视频创作全流程，内置 Seedance 2.0 模型
- 从脚本、分镜到视频生成，支持导出剪映工程文件
- 多人协作：团队内全项目文件共享（角色、道具、文档等）
- 资产实时共享与沉淀

### 2.6 跨端接力
- 桌面端：系统级沉浸式工作台，Agent 直接处理本地文件（大文件、多文件）
- 移动端：多人多 Agent 协作，任务跨端实时同步，手机遥控电脑文件
- 跨端协同：编程项目对话开发、远程部署；视频项目对话创作、修改片段

## 3. 交互设计亮点

- 消息颜色/头像区分人类和 Agent
- Agent 消息包含：头像、名称、状态（正在看飞书文档...）、时间戳
- 文件交付：Promo-Video-Script.md 等文件卡片
- 产物内联展示（视频、网页等）
- / 命令快速引用技能或文件
- 多平台同步：桌面端 + App + 网页

## 4. 底层技术推断

- 前端：Electron（桌面端）+ React Web（网页）+ Flutter/React Native（移动端）
- 后端：分布式消息服务，多模型网关（统一适配不同 LLM 厂商）
- 沙箱：云端容器（开发环境隔离）+ 本地文件授权（桌面端桥接）
- 长期记忆：向量数据库 + 用户画像持续更新
- 技能系统：插件化架构，/ 命令触发
- 部署：云原生 CI/CD，内建域名、SSL、CDN

## 6. 复刻要点

1. 先实现核心群聊 + Orchestrator 调度（赛题 P0）
2. 再接入本地工具（Claude Code、Codex）作为 Agent（赛题 P0）
3. 云端沙箱环境（编程项目）可以作为 P2 加分项
4. 视频创作能力可以作为差异化亮点（P2）
5. 跨端（桌面端 + 移动端）是 P2 加分项
6. 长期记忆和用户画像可以作为后续迭代
