#### **AgentHub - 多 Agent 协作平台(目前选择)**

在大模型与 AI Agent 技术快速发展的背景下，多 Agent 协作已成为提升复杂任务执行效率的关键趋势。本课题聚焦 AI 驱动的开发与协作场景，要求学生基于统一适配器层与主流 Agent 平台（如 Claude Code、Codex），打造一个 IM 聊天式的多 Agent 协作平台（AgentHub）。 AgentHub 系统致力于实现类似飞书/微信的自然交互体验，支持单聊、多会话并行以及通过 @ 指令实现的群聊协作；同时集成 Orchestrator 协调器进行任务拆解，并提供代码 Diff、网页预览及一键部署等全流程功能。课题不仅考察系统的功能完整度与用户体验，更强调参赛者在 TRAE 协作、Prompt 工程及架构选型中的创新思考与实践。
