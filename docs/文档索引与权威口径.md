## 当前核心口径

- AgentHub 正在从旧 DAG-first 流程系统转向 Manager-first 团队运行时。
- Manager / Orchestrator 是主脑，像团队负责人一样理解目标、协调 Worker、验收结果和向人类汇报。
- Planner 不再是主脑；结构化拆解只是 Manager 可调用的 planning skill / action。
- `OrchestratorEngine` 只是迁移期执行兼容层，后续应继续拆到 `RunController / ManagerLoop / WorkerController`。
- A2A 是通信协议，不是 Agent 类型。
- AG-UI 是运行事件到前端的投影协议，不是业务状态源本身。
- MCP、Skills、Rules 是 Code Agent 能力层，不是 Agent 类型。
- Codex CLI、Claude Code、OpenCode、Gemini CLI 是主要 Worker 基底。
- OpenClaw / CoPaw 更适合作为后续 CoordinatorRuntime / ManagerRuntime 候选，不要硬塞成普通 `codeAgentType`。
- 新内核方向已经明确为 AgentHub Product Shell + HiClaw-lite Open Kernel：前端产品壳保留，底层通信采用 Matrix，Manager/Worker Runtime 学 HiClaw，Worker 继续强化 Claude Code / OpenCode / Codex / Gemini。
- A2A 暂不作为内部主通信路径；在 Matrix 成为通信事实源后，A2A 只保留为外部互操作或 Matrix event 中的可选任务语义 envelope。
- `docs/hiclaw-wiki.agent.final.md` 和本地 `hiclaw源码参考/` 是后续 HiClaw-lite 重构的主要参考依据。
- 当前仍处开发阶段，旧会话、旧任务、旧数据库和旧 workspace/storage 数据不再是架构约束；必要时可以清库，以新内核重新初始化。
- 不恢复固定场景模板、关键词路由、静态兜底内容、自动 Researcher/QA 注入、`classic` 模板、`workspace-agent-child`。
