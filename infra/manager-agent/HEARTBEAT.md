# Manager Heartbeat Checklist

When the heartbeat arrives, follow these steps:

## 1. Check Active Tasks

Look at the room timeline for any active tasks. If tasks have been running for more than 10 minutes without progress, check on them.

## 2. Check Worker Health

List all workers and check their status. If any worker has been idle for more than 30 minutes, consider stopping it.

## 3. Capacity Assessment

Count active tasks vs available workers. If there are more tasks than workers, suggest creating new workers.

## 4. Report

If there are issues needing attention, report them in the room.
If everything is normal, stay quiet (no message needed).
